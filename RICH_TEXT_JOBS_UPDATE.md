- Toolbar with: Bold, Italic, Bullet lists, Numbered lists

## How to Test

### Step 1: Create a Test Job with Rich Content

1. Navigate to: `http://localhost:3001/admin/jobs/new`
2. Fill in:
   - **Job Title**: "Senior Software Engineer"
   - **Job Summary**: "We're looking for an experienced engineer to lead our backend team."
   - **Job Description**: Use the rich text editor to create content like:
     ```
     About the role:
     This is an exciting opportunity to join our team as a Senior Software Engineer.
     
     Key Responsibilities:
     • Lead the backend architecture and design
     • Mentor junior engineers
     • Collaborate with product team
     • Own deployment and monitoring
     
     Required Skills:
     • 5+ years of software development experience
     • Strong understanding of distributed systems
     • Experience with modern cloud platforms
     
     Nice to Have:
     1. Experience with microservices architecture
     2. Knowledge of containerization (Docker/Kubernetes)
     3. Open source contributions
     ```
   - **Location**: "New York, NY"
   - **Employer**: Select one (optional)
   - **Public**: Checked

3. Click "Create Job"

### Step 2: View on Candidate-Facing Page

1. Go to: `http://localhost:3001/candidate/jobs`
2. You should see:
   - The job summary (1-2 sentences) on the listing card
   - The title and location
   - "View Details" button

3. Click "View Details" or go directly to the job detail page

### Step 3: Verify Rich Text Rendering

On the job detail page (`/candidate/jobs/[jobId]`), verify:
- ✅ **Bold text** renders as bold (not `<strong>` tags)
- ✅ **Italic text** renders as italic (not `<em>` tags)
- ✅ **Bullet lists** are properly indented and bulleted
- ✅ **Numbered lists** show numbers properly (1., 2., 3., etc.)
- ✅ **No raw HTML tags** visible (content is properly sanitized)

### Step 4: Edit the Job

1. Go to: `http://localhost:3001/admin/jobs`
2. Click the job you just created
3. Click "Edit"
4. Modify the rich text description:
   - Add some bold text
   - Add some italic text
   - Click the toolbar buttons (B, I, • List, 1. List)
5. Click "Save Changes"
6. Go back to the candidate detail page and verify changes

## Field Definitions

### Job Summary (Plain Text)
- **Purpose**: Short hook shown on job listing cards
- **Length**: 200 characters max
- **Format**: Plain text (no formatting)
- **Display**: Truncated to 3 lines on listing cards
- **Hint**: "1-2 sentences, shown on the job listing card"

### Job Description (Rich Text)
- **Purpose**: Full job posting with formatting
- **Format**: HTML (generated by Tiptap editor)
- **Storage**: `jobs.description` column (text type)
- **Display**: Uses `<RichTextDisplay />` component on public pages
- **Support**: Bold, Italic, Bullet Lists, Numbered Lists

## Editor Toolbar

The RichTextEditor component includes:

| Button | Action | Keyboard |
|--------|--------|----------|
| **B** | Bold | Ctrl+B |
| **I** | Italic | Ctrl+I |
| • List | Bullet List | Ctrl+Shift+8 |
| 1. List | Ordered List | Ctrl+Shift+7 |

## CSS Classes

The RichTextDisplay component uses Tailwind's `prose` classes for styling. The current setup respects:
- Font sizes and line heights from prose
- List indentation and markers
- Text formatting (bold, italic)
- Proper spacing between elements

To customize appearance, modify the `className` prop when using `<RichTextDisplay />`.

## Known Limitations

- No support for: headings, tables, code blocks, images, colors
- HTML is stored as-is (Tiptap JSON output serialized to HTML)
- Rich content is sanitized via dangerouslySetInnerHTML with appropriate guards
- No export/import of rich content formats (Markdown, Word docs, etc.)

## Troubleshooting

### Editor not loading
- Ensure Tiptap packages are installed: `npm install`
- Check browser console for errors
- Verify JavaScript is enabled

### Content not saving
- Check that description field contains HTML (should start with `<p>` tags)
- Verify job_summary field is populated (plain text, not empty)
- Check browser console for validation errors

### Rendering shows raw HTML
- Ensure `<RichTextDisplay />` component is used (not just `<p>{job.description}</p>`)
- Check that `dangerouslySetInnerHTML` is working
- Verify the component is imported correctly
